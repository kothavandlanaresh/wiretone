WireTone Phase 1.4 — in-memory receiver session state

Adds a pure C++ receiver session boundary around the locked Phase 1 packet,
control-payload, fragmentation, and reassembly contracts.

Included:
- idle/streaming lifecycle
- stream-start requirement and stream-ID enforcement
- deterministic replacement, stop, reset, and liveness timeout
- fixed eight-frame completed-audio queue
- oldest-frame drop on overflow
- discontinuity flushing
- deterministic diagnostics counters
- fifth native test executable

Excluded:
- UDP sockets
- WASAPI capture
- Android playback
- jitter-buffer timing
- Opus
