WireTone Phase 1.3.1 — Windows bootstrap PATH-length fix

Problem
-------
The old bootstrap called VsDevCmd.bat and imported every resulting environment
variable into the current PowerShell process. Repeated runs could inflate PATH
until cmd.exe hit its legacy command-line limit and returned:

    The input line is too long.

Fix
---
- Discover cl.exe directly from the installed MSVC toolset.
- Stop importing the Visual Studio developer environment into the parent shell.
- Let CMake's Visual Studio generator locate and drive MSBuild directly.
- Configure the Windows build explicitly for x64.

Scope
-----
Build scripts only. No protocol, audio-frame, Android, or runtime code changes.

Apply this archive over the repository root, then rerun:

    .\scripts\check-environment.ps1
    .\scripts\bootstrap-windows.ps1
